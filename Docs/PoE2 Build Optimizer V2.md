PHASE V2-6
ITEM RECOMMENDATION ENGINE
============================================================

Goal
------------------------------------------------------------

Recommend realistic upgrades.

Not:

Perfect theoretical items.

Instead:

Achievable upgrades.

Principle:

Recommend realistic upgrades to the
current build.

Do not redesign the build into a
different archetype.

Preserve build identity whenever
possible.

Example:

Current Ring
    ↓
Suggested Upgrade

Current Weapon
    ↓
Suggested Upgrade

Current Jewel
    ↓
Suggested Upgrade

Output:

Upgrade Priority List
